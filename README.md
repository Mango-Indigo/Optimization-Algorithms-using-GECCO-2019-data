# Optimization-Algorithms-using-GECCO-2019-data

This repository experiments with different optimization algorithms (that calculate the optimal answer) using the problem data from the GECCO 2019 challenge. <br>
The data used has ben taken from [GECCO 2019](https://github.com/blankjul/gecco19-thief/tree/master/target/classes/resources) and can be found in the datasets folder. <br><br>


There are two main problem types solved:
1. Travelling Salesman Problem (TSP)
2. Travelling Thief Problem (TTP) <br>

To run the python code download the repo and the run the run file in each folder.
