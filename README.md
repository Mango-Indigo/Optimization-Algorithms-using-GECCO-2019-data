# Optimization-Algorithms-using-GECCO-2019-data

This repository experiments with different optimization algorithms (that calculate the optimal answer) using data from the GECCO 2019 challenge. The data used has ben taken from GECCO 2019 and can be found in the datasets folder. 
There are two main problem types solved:
Travelling Salesman Problem
Travelling Thief Problem
To run the python code download the repo and the run the run file in each folder.
